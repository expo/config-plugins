# @config-plugins/ios-metal-api-validation

Expo Config Plugin to disable [Metal API validation](https://developer.apple.com/documentation/xcode/validating-your-apps-metal-api-usage) in the Xcode scheme generated by `npx expo prebuild`.

This is required to run libraries such as [`react-native-webgpu`](https://github.com/wcandillon/react-native-webgpu) on the iOS Simulator, where Metal API validation raises errors for GPU features that work fine on a physical device.

It applies the same change as unchecking **Product > Scheme > Edit Scheme > Run > Diagnostics > Metal Validation** in Xcode, by adding `enableGPUValidationMode = "1"` to the `LaunchAction` of the shared `.xcscheme`. It only affects builds launched from Xcode or `npx expo run:ios`; release builds and App Store builds never have Metal API validation enabled.

## Versioning

Ensure you use versions that work together!

| `expo` | `@config-plugins/ios-metal-api-validation` |
| ------ | ------------------------------------------ |
| 56.0.0 | 1.0.0                                      |

## Expo installation

> This package cannot be used in the "Expo Go" app because [it requires custom native code](https://docs.expo.io/workflow/customizing/).

First install the package with yarn, npm, or [`npx expo install`](https://docs.expo.io/workflow/expo-cli/#expo-install).

```sh
npx expo install @config-plugins/ios-metal-api-validation
```

After installing this npm package, add the [config plugin](https://docs.expo.io/guides/config-plugins/) to the [`plugins`](https://docs.expo.io/versions/latest/config/app/#plugins) array of your `app.json` or `app.config.js`:

```json
{
  "expo": {
    "plugins": ["@config-plugins/ios-metal-api-validation"]
  }
}
```

Next, rebuild your app as described in the ["Adding custom native code"](https://docs.expo.io/workflow/customizing/) guide.

## API

The plugin provides props for extra customization. Every time you change the props or plugins, you'll need to rebuild (and `prebuild`) the native app. If no extra properties are added, defaults will be used.

- `apiValidation` (_boolean_): Whether Metal API validation should be enabled in the generated scheme. Default `false` (adding the plugin disables validation).

#### Example

```json
{
  "expo": {
    "plugins": [
      [
        "@config-plugins/ios-metal-api-validation",
        {
          "apiValidation": false
        }
      ]
    ]
  }
}
```
